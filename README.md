# YAKAR beşli web sitesi

`index.html` ana sayfadır. `kagit`, `plastik`, `cam`, `metal` ve `pil` klasörleri ilgili atık sayfalarını içerir.

GitHub Pages için bu klasörün **içindekileri** deponun köküne yükleyin. Depo ayarlarından Pages > Deploy from a branch > main > /(root) seçin. Yayın adresi belirlendiğinde QR kodunu o kesin adresle yeniden oluşturun.

Sayfalarda API anahtarı yoktur; soru-cevap bölümleri hazır bilgi yanıtları kullanır.
